    How it works
    
      
    Every upload goes through the same four steps, using exactly the preprocessing the model was trained with.
    
    
    
    
      
      
    1. Validate
      The file is checked from its contents, not its name. Only real JPEG and PNG images are accepted.
      2. 
      
    2. Preprocess
      The image is converted to RGB and resized to 224 × 224. ImageNet normalisation happens inside the model.
      3. 
      
    3. Classify
      A ResNet50 pretrained on ImageNet and fine-tuned on brain MRIs outputs a probability for each class.
      4. 
      
    4. Explain
      Grad-CAM traces the prediction back to the last convolutional layer to show where the model looked.

    The four tumour types
    
      
    
    
    
    
      
    Glioma
    Grows from the glial cells that support neurons. Often has irregular, poorly defined borders.
    
      
    Meningioma
    Grows from the meninges, the membranes around the brain, and usually presses inward from the edge.
    
      
    Pituitary
    Grows in the pituitary gland at the base of the skull, below the centre of the brain.
    
      
    No tumour
    A healthy slice with no visible tumour. The model recognised every one of these in the test set.
